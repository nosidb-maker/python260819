세 가지 레이어

웹페이지는 이 세 층이 함께 작동합니다.

01

HTML5 · 구조

HTML은 웹페이지에 제목, 글, 이미지 같은 내용을 배치하는 언어입니다.

기억법: 집의 벽과 방을 만드는 설계도
<h1>오늘의 제목</h1>
<p>반가워요!</p>
콘텐츠의 뼈대
02

CSS3 · 표현

CSS는 HTML로 만든 내용에 색, 크기, 위치, 간격을 입히는 언어입니다.

기억법: 집의 페인트와 가구를 고르는 인테리어
h1 {
  color: #287a5a;
}
화면의 분위기
03

JavaScript · 동작

JavaScript는 클릭, 입력 같은 사건에 반응해 화면을 움직이는 언어입니다.

기억법: 집의 스위치와 자동문을 움직이는 전기 장치
button.addEventListener('click', () => {
  alert('환영합니다!');
});
상호작용의 시작

한 문장으로 정리하기

HTML로 내용을 만들고 → CSS로 보기 좋게 꾸미고 → JavaScript로 사용자의 행동에 반응하게 만듭니다.
