# 🌟 신나는 한글 탐험대 (Hangul Kids Adventure)

> **6세 아이의 눈높이에 맞춘 인터랙티브 놀이형 한글 학습 웹 애플리케이션**

---

## 🎯 4대 핵심 놀이 모드

1. 🚂 **자모음 합체 기차 (원리 이해)**
   - 자음 카트(`ㄱ, ㄴ, ㄷ...`)에 모음 승객(`ㅏ, ㅓ, ㅗ...`)을 태우면 `"그" + "아" = "가!"` 소리와 함께 기차가 출발합니다.
   - 한글의 과학적인 음절 결합 원리를 자연스럽게 체득합니다.

2. 🎈 **풍선 팡팡 단어 퀴즈 (시청각 매칭)**
   - 귀여운 동물/사물/공룡 이모지와 힌트 음성을 듣고, 하늘에 떠다니는 알맞은 글자 풍선을 터뜨려 단어를 완성합니다.

3. ⭐ **별자리 따라쓰기 (운필력 & 형태 인지)**
   - 별을 잇듯 반짝이는 무지개 빛 브러시로 글자를 직접 써보며 획순과 형태를 익히고 완성 도장을 받습니다.

4. 📖 **모험 동화책 (스토리 & 스티커북)**
   - 별을 모아 새로운 동화 페이지와 탐험 칭찬 스티커를 해금하고, 이야기를 실감나는 음성으로 들어봅니다.

---

## 🚀 실행 방법

### 방법 1. 브라우저에서 바로 열기
1. `c:\workAnti\HangulKids\index.html` 파일을 더블 클릭하여 크롬(Chrome)이나 엣지(Edge) 브라우저에서 열면 즉시 실행됩니다. (태블릿/PC 모두 지원)

### 방법 2. 로컬 웹 서버 실행 (오디오 및 모듈 최적화 권장)
```bash
python -m http.server 8080 --directory c:\workAnti\HangulKids
```
브라우저 주소창에 `http://localhost:8080` 입력

## 🦖 테마 선택 기능
- 🦖 **공룡 탐험대**: 티라노, 트리케라톱스 등 공룡 친구들과 함께하는 모험
- 🚗 **붕붕 탈것 마을**: 기차, 소방차, 비행기 등 신나는 탈것 세상
- 🦁 **귀여운 동물 숲**: 사자, 토끼, 코끼리 등 다정한 동물 친구들
- 🚀 **신비한 우주 여행**: 로켓, 별, 외계인과 함께 떠나는 우주 탐험

## ⏱️ 부모님 안심 케어 기능
- **15분 놀이 타이머**: 아이의 시력 보호와 올바른 미디어 습관을 위해 15분 후 귀여운 휴식 안내창이 나타납니다.
- **음성 읽어주기 (TTS) & 음소 음향**: 모든 글자와 단어의 표준 발음을 들려줍니다.
